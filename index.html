Dusk APT repository

Signed packages for DuskOS: the Dusk desktop, Security Hub and shdefender. Suites stonking, resolute, component main, amd64.

Add the repository

sudo curl -fsSLo /usr/share/keyrings/dusk-archive-keyring.gpg \
    https://phlthydelphya.github.io/dusk-apt/dusk-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/dusk.sources \
    https://raw.githubusercontent.com/phlthydelphya/dusk-apt/main/keyring/dusk.sources
sudo sed -i "s/^Suites: .*/Suites: $(. /etc/os-release; echo "$VERSION_CODENAME")/" /etc/apt/sources.list.d/dusk.sources
sudo apt update
sudo apt install dusk-archive-keyring
